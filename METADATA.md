1\. **425\_Operational\_Targets.zip**. This zipped folder contains all 425 reservoir datasets with their respective operational guide curves and release policies generated from the **WaDorule framework**. Each reservoir file is named with a given number, followed by the managing agency. Each reservoir csv file contains three columns, i.e. "**target\_stor\_final**" in **MCM**; "**target\_rel\_final**" in **m^3/s** and "**target\_elev\_final**" in **m.**



2\. **Selected\_WaDorule\_Dams.csv**. This file contains the 25 dams selected from the large database of 425. The file has nine columns with different headers i.e., "**Dam Name**", "**State**", "**Latitude**", "**Longitude**",	"**Agency**", "**Operational Target**", "**Main Purpose**", "**Other Uses**", "**Storage (AF)**".



3\. **Reservoirs\_25.csv**. This file contains derived release policies for 25 selected reservoirs



4\. List of 4 selected reservoirs in the names of **Garrison**, **Hoover**, **John\_Kerr** and **Sam\_Rayburn**. These reservoirs have their respective inflows name as **...\_inflows.csv** and operational target named as **...\_targets.csv**



5\. **NCA\_7\_regions.zip**. This zipped folder contains CONUS 7 regions shapefile



6\. **CONUS\_USA\_Climatezones.json**. This file is for climate regions of CONUS.



7\. **R\_Code\_Analysis.R**. This file contains codes that used to perform analysis for this paper
